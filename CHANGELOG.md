# Changelog

All notable changes to Vibe flow will be documented in this file.

## [0.1.0] — 2026-07-22

### Added
- Initial project scaffolded from Google AI Studio
- Dashboard with KPIs, agent status matrix, MCP integration hub, and 3-layer security insights
- Agent Hub — CRUD for AI agents with status, memory, capabilities, and multimodal controls
- Command Center — real-time chat with Gemini Flash/Pro streaming and TTS audio synthesis
- MCP Gateway — tool integration hub with Salesforce, PostgreSQL, and HubSpot connectors (mock)
- Approval Queue — human-in-the-loop oversight for critical agent actions
- Audit Logs — immutable event trail for compliance
- White-Label Branding — custom logos, colors, typography, and live preview
- Multi-language support (pt-BR, en-US, es-ES) via LanguageContext
- Dark/Light theme toggle via ThemeContext
- Login page with email/password and OAuth providers (GitHub, Google)

### Changed
- Renamed project from "JulIA" to "Vibe flow" across all source files and locales
- Updated email domain from @julia.ai to @vibeflow.ai

### Documentation
- Added PRD.md, AGENT.md, CLAUDE.md, GEMINI.md, SOUL.md, ROADMAP.md, TASKS.md, ARCHITECTURE.md
